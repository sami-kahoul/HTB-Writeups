# Hack The Box Writeups

This repository contains my Hack The Box writeups documenting the methodology used during each machine assessment, including:

* Enumeration
* Vulnerability Identification
* Initial Access
* Privilege Escalation
* Post-Exploitation
* Lessons Learned

The purpose of this repository is to document my learning process, improve technical reporting skills, and maintain a portfolio of practical penetration testing experience.

> **Note:** This repository contains writeups for retired Hack The Box machines only, in accordance with Hack The Box's content-sharing policy.
